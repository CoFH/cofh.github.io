---
title: stalagmite
---

**`stalagmite`** is one of the [feature types](../) provided by [CoFH
World](../../../). It generates upwards pointing spikes. The shape of these
spikes is different than those generated using [`spike`](../spike/).

Stalagmites are only generated on the surface or underground. They are never
generated in midair.

The value `material` of a [feature type
configuration](../../feature-format/#feature-type-configuration) is only used to
determine the position of stalagmites. When generating the stalagmites
themselves, the option `gen-body` is used instead.


Options
-------

When using this feature type, the following values must be added to the [feature
type configuration](../../feature-format/#feature-type-configuration).

            <tr>
                <th>Name</th>

                <th>Default</th>

        </thead>
        <tbody>
            <tr>
                <td>`block`</td>
                <td>[Block ID](../../common-formats/block-id/) / array of block IDs</td>
                <td>-</td>
                <td>The type(s) of block that stalagmites consist of. When specified as an array, a
                  block type is selected randomly for each generated block.</td>
            </tr>
            <tr>
                <td>`gen-body` (optional)</td>
                <td>[Block ID](../../common-formats/block-id/) / array of block IDs</td>
                <td>Air</td>
                <td>The type(s) of block that may be replaced to generate stalagmites.</td>
            </tr>
            <tr>
                <td>`min-height` (optional)</td>
                <td>Number</td>
                <td>`7`</td>
                <td>The minimum height of a stalagmite, in blocks.</td>
            </tr>
            <tr>
                <td>`height-variance` (optional)</td>
                <td>Number</td>
                <td>`4`</td>
                <td>The maximum amount of blocks that may be randomly added to the minimum height of
                  a stalagmite.</td>
            </tr>
            <tr>
                <td>`height-mod` (optional)</td>
                <td>Number</td>
                <td>`5`</td>
                <td>Used to calculate the minimum radius of the base of a stalagmite dynamically.
                  The radius is equal to the height of the stalagmite divided by this value. Only
                  used if `gen-size` is set to `0`.</td>
            </tr>
            <tr>
                <td>`gen-size` (optional)</td>
                <td>Number</td>
                <td>`0`</td>
                <td>The minimum radius of the base of a stalagmite, in blocks. If set to `0`, the
                  radius is calculated dynamically based on the stalagmite's height.</td>
            </tr>
            <tr>
                <td>`size-variance` (optional)</td>
                <td>Number</td>
                <td>`2`</td>
                <td>The maximum amount of blocks that may be randomly added to the minimum radius of
                  the base of a stalagmite.</td>
            </tr>
            <tr>
                <td>`smooth` (optional)</td>
                <td>Boolean</td>
                <td>`false`</td>
                <td>If `true`, stalagmites have a smoother shape from bottom to top. If `false`,
                  they are more narrow towards the top, making them more pointy.</td>
            </tr>
            <tr>
                <td>`fat` (optional)</td>
                <td>Boolean</td>
                <td>`true`</td>
                <td>If `true`, stalagmites are wider from bottom to top.</td>
            </tr>
            <tr>
                <td>`alt-sinc` (optional)</td>
                <td>Boolean</td>
                <td>`false`</td>
                <td>If `true`, the sides of stalagmites are shaped more unevenly, making them look
                  more natural. This is more obvious when `smooth` is set to `true`.</td>
            </tr>
        </tbody>
    </table>
</div>
